# 💻 Code Lab – All-in-One Code Collection

A growing collection of useful codes, scripts, tools, experiments, and programming projects built for different purposes.

Works best with Microsoft Surface Laptop Ultra, Microsoft Surface Pro, Samsung Book Go, and Windows PCs and Apple Devices.
(Warning: Not Compatible with Androids that have cheap cpu) 
Use at you own risk.

Welcome to **Code Lab**.

This repository is a collection of different programming projects covering multiple languages, categories, and everyday uses. From browser tools and productivity scripts to automation, utilities, experimental programs, and fun little projects.

The goal is simple: build useful things, learn new techniques, experiment with code, and keep everything organized in one place.

---

## 🧰 What's Inside?

Code Lab contains a variety of projects, including:

- 🌐 **Browser Tools** – Bookmarklets, browser enhancements, and useful web utilities.
- ⚙️ **Automation** – Scripts designed to simplify repetitive tasks.
- 🔐 **Cybersecurity Education** – Defensive security tools, password-strength checkers, and security demonstrations.
- 💻 **System Utilities** – Small programs for everyday computer tasks.
- 📁 **File Management** – Tools for organizing and working with files.
- ⏱️ **Productivity** – Timers, reminders, calculators, and other useful tools.
- 🤖 **AI & Experiments** – Experimental projects involving artificial intelligence.
- 🎮 **Fun Projects** – Random experiments, interactive programs, and interesting ideas.
- 🧪 **Code Experiments** – Projects exploring different programming techniques.

## 🚀 Getting Started

1. Browse through the folders.
2. Find a project that interests you.
3. Open its source code.
4. Read the instructions included with that project.
5. Install any required dependencies.
6. Run it in the appropriate environment.

Some projects may work directly in a browser, while others require a programming environment.
